🤔 fs puro vs Bancoz

Veja a diferença de complexidade para uma operação simples: salvar um usuário em JSON.

🔴 Com fs (Node.js puro)

import fs from 'fs';
import path from 'path';

const filePath = path.join('./data', 'usuarios.json');

let data = {};
if (fs.existsSync(filePath)) {
    const raw = fs.readFileSync(filePath, 'utf-8');
    data = JSON.parse(raw);
}

data['joao'] = {
    nome: 'João Silva',
    idade: 30,
    email: 'joao@email.com'
};

fs.writeFileSync(filePath, JSON.stringify(data, null, 2), 'utf-8');
console.log('Salvo!');
⬇️ bem mais simples ⬇️

🟢 Com Bancoz

import bancoz from 'bancoz';

bancoz.fila(true);
bancoz.bk(true);

await bancoz.criar('usuarios', 'joao', {
    nome: 'João Silva',
    idade: 30,
    email: 'joao@email.com'
});
console.log('Salvo!');

Resultado: 1 linha de operação vs 10+ linhas. Sem preocupação com parse, encoding, diretórios inexistentes ou conflitos de escrita. O Bancoz cuida de tudo.

⚙️ Configuração Inicial

A biblioteca armazena todos os arquivos em uma pasta chamada BANCO Z no diretório do projeto por padrão. Você também pode trocar a pasta raiz com bancoz.path('caminho'). A estrutura é criada automaticamente.

📌 Nota: Todos os arquivos são salvos com extensão .json automaticamente. Não é necessário especificar a extensão. Subpastas como tuc/users também são suportadas. 
import bancoz from 'bancoz';

// Configurações básicas
bancoz.fila(true);    // Ativa fila de operações
bancoz.bk(true);      // Ativa modo backup
bancoz.log(true);     // Ativa sistema de log
bancoz.lang('pt');    // Define idioma português

// Opcional: muda a pasta raiz local
bancoz.path('./up/bancoz');

// Opcional: cache em memória
bancoz.cache(true, 10); // cache por 10 minutos

Configurações

fila(boolean) / queue(boolean)
Ativa ou desativa a fila de operações. Quando ativa, operações concorrentes são executadas em sequência para evitar conflitos.
Parâmetros:
  • valor (boolean): true para ativar, false para desativar
Exemplo: 
bancoz.fila(true);  // Ativa fila
bancoz.queue(false); // Desativa fila (inglês)
bk(boolean) / backup(boolean)
Ativa modo backup. Cria uma cópia do arquivo antes de cada alteração. Em caso de erro, restaura automaticamente.
Parâmetros:
  • valor (boolean): true para ativar backup
log(boolean) / logAtivo(boolean)
Ativa sistema de log. Registra todas as operações em arquivo log.txt na pasta BANCO Z.
lang(string) / language(string)
Define o idioma dos logs e mensagens.
Parâmetros:
  • idioma (string): 'pt' para português, 'en' para inglês
api_key(string|null)
**v2.0.8** Ativa modo remoto (API cloud) ou retorna local. CRUD funciona igual!
Exemplo:
  • bancoz.api_key('sua_key') → remoto
  • bancoz.api_key(null) → local BANCO Z
path(caminhoDaPasta|null)
Define a pasta raiz usada pelo Bancoz no modo local. Se não for chamado, continua usando BANCO Z. Ao trocar o path, o cache em RAM é limpo para evitar mistura entre bases diferentes.
Parâmetros:
  • caminhoDaPasta (string|null): pasta customizada ou null para voltar ao padrão
Exemplo: 
bancoz.path('./up/bancoz');
await bancoz.criar('users', 'joao', { nome: 'João' });

bancoz.path(null); // Volta para BANCO Z/
cache(boolean, minutos?)
Ativa cache em memória por arquivo no modo local. A primeira leitura carrega do disco e as próximas vêm da RAM. Escritas atualizam a RAM primeiro e depois sincronizam no disco. Se o tempo não for informado, o cache não expira.
Parâmetros:
  • valor (boolean): true para ativar, false para desativar
  • minutos (number, opcional): tempo de vida do cache por arquivo
Exemplo: 
bancoz.cache(true);      // Sem expiração
bancoz.cache(true, 10);  // Expira em 10 minutos
bancoz.cache(false);     // Desativa e limpa
getCache(exibirTerminal?, modo?)
Mostra o estado atual do cache sem alterar o conteúdo. É uma ferramenta de inspeção/debug para visualizar apenas o que já está carregado na memória. Não é uma forma de recuperar dados do banco; para isso use ler() / read(). Use "files" para listar arquivos e "data" para mostrar os dados separados por arquivo no terminal.
Parâmetros:
  • exibirTerminal (boolean): true imprime no terminal; false retorna apenas nomes/metadados
  • modo (string): "files" ou "data"
Exemplo: 
bancoz.getCache(true, 'files'); // Lista arquivos
bancoz.getCache(true, 'data');  // Mostra conteúdos no terminal

const cache = bancoz.getCache(false, 'data');
console.log(cache.arquivos); // Nomes/metadados, sem conteúdo

🔧 Métodos Principais

PT criar(arquivo, no, dados) EN create(file, node, data)
Cria um novo nó com os dados especificados. Se o arquivo não existir, é criado automaticamente.
Parâmetros:
  • arquivo (string): Nome do arquivo (sem .json). Aceita subpastas, exemplo: tuc/users
  • no (string): Identificador do nó
  • dados (any): Dados a serem salvos
Exemplo: 
await bancoz.criar('usuarios', 'joao', {
    nome: 'João Silva',
    idade: 30,
    email: 'joao@email.com'
});

// Em inglês
await bancoz.create('products', '123', {
    name: 'Notebook',
    price: 2500
});

// Subpasta dentro da pasta raiz do Bancoz
await bancoz.criar('tuc/users', 'maria', {
    nome: 'Maria'
});
PT ler(arquivo, no) EN read(file, node)
Lê os dados de um nó específico. Retorna null se o nó não existir.
Exemplo: 
const usuario = await bancoz.ler('usuarios', 'joao');
console.log(usuario);

const product = await bancoz.read('products', '123');
PT atualizar(arquivo, no, dados, chave?) EN update(file, node, data, key?)
Atualiza dados de um nó. Oferece múltiplas formas de atualização:
Formas de uso:
  • Atualizar chave específica: passe o nome da chave como 4º parâmetro
  • Atualização parcial: passe um objeto com as chaves a atualizar
  • Substituir nó completo: passe o objeto completo e omita a chave
Exemplos: 
// Atualizar chave específica
await bancoz.atualizar('usuarios', 'joao', 31, 'idade');

// Atualização parcial (só chaves existentes)
await bancoz.atualizar('usuarios', 'joao', {
    idade: 32,
    email: 'joao.novo@email.com'
});

// Substituir nó completo
await bancoz.atualizar('usuarios', 'joao', {
    nome: 'João Modificado',
    status: 'ativo'
});
PT deletar(arquivo, no, chaves?) EN delete(file, node, keys?)
Deleta um nó inteiro ou chaves específicas dentro dele.
Formas de uso:
  • Deletar nó inteiro: omita o 3º parâmetro
  • Deletar chave específica: passe string com o nome da chave
  • Deletar múltiplas chaves: passe array de strings
Exemplos: 
// Deletar nó inteiro
await bancoz.deletar('usuarios', 'joao');

// Deletar chave específica
await bancoz.deletar('usuarios', 'joao', 'email');

// Deletar múltiplas chaves
await bancoz.deletar('usuarios', 'joao', ['email', 'telefone']);
PT pesquisar(termo, alvo) EN search(term, target)
Pesquisa uma palavra-chave ou frase nos arquivos JSON da pasta do banco e retorna somente os caminhos onde encontrou correspondência, sem trazer os dados completos.
Parâmetros:
  • termo (string): palavra-chave ou frase para pesquisar
  • alvo (string): "*" para todos os arquivos ou um arquivo específico dentro da pasta do banco
Exemplos: 
// Pesquisa em todos os arquivos da pasta do banco
const resultado = await bancoz.search('cafe especial', '*');

// Pesquisa em um arquivo específico dentro da pasta do banco
const usuarios = await bancoz.pesquisar('joao', 'usuarios');

console.log(resultado);
// {
//   "produtos/catalogo.json": [
//     "$.item1.titulo"
//   ]
// }
Segurança: o caminho do arquivo fica restrito à pasta do banco. Caminhos como ../package.json são bloqueados.

📝 Exemplos de Uso

Exemplo Básico

import bancoz from 'bancoz';

async function exemplo() {
    // Configuração
    bancoz.fila(true);
    bancoz.bk(true);
    bancoz.log(true);
    bancoz.lang('pt');

    try {
        // Criar usuário
        await bancoz.criar('clientes', 'maria', {
            nome: 'Maria Santos',
            idade: 28,
            email: 'maria@email.com',
            endereco: {
                cidade: 'Rio de Janeiro',
                uf: 'RJ'
            }
        });

        // Atualizar idade
        await bancoz.atualizar('clientes', 'maria', 29, 'idade');

        // Adicionar telefone
        const dados = await bancoz.ler('clientes', 'maria');
        dados.telefone = '2199999999';
        await bancoz.atualizar('clientes', 'maria', dados);

        // Ler dados atualizados
        const cliente = await bancoz.ler('clientes', 'maria');
        console.log('Cliente:', cliente);

    } catch (erro) {
        console.error('Erro:', erro);
    }
}

exemplo();

Exemplo Avançado com Operações Concorrentes

import bancoz from 'bancoz';

async function exemploConcorrente() {
    bancoz.fila(true); // Fila evita conflitos
    bancoz.bk(true);   // Backup por segurança

    // Criar contador inicial
    await bancoz.criar('contador', 'valor', 0);

    // Simular 10 operações concorrentes
    const operacoes = [];
    for (let i = 0; i < 10; i++) {
        operacoes.push((async () => {
            const valor = await bancoz.ler('contador', 'valor');
            await bancoz.atualizar('contador', 'valor', valor + 1);
            console.log(`Operação ${i}: ${valor + 1}`);
        })());
    }

    await Promise.all(operacoes);

    const final = await bancoz.ler('contador', 'valor');
    const global = await bancoz.ler('contador');
    console.log('Valor final:', final); // Sempre 10 graças à fila
}

import bancoz from 'bancoz';

async function exemploLimitesAvancados() {
    await bancoz.limiteAvancado('demo.json', {
        "0": { maxKeys: 3 },
        "1": { maxKeys: 2 }
    });

    await bancoz.criar('demo.json', 'user1', {
        nome: 'João',
        dados: { idade: 30, cidade: 'SP' }
    });
    await bancoz.criar('demo.json', 'user2', { nome: 'Maria' });

    console.log('Max depth:', status.atual.maxDepth);

    try {
        await bancoz.criar('demo.json', 'user4', { nome: 'Erro' });
    } catch (e) {
        console.log('Erro esperado:', e.message);
    }
}

📏 Novos Métodos v1.0.7

PT limite(arquivo, nodes?, subnodes?, arrays?) EN setLimit(file, nodes?, subnodes?, arrays?)
Define limites de tamanho para arquivo específico. Salva em BANCO Z/configs/bancoz/limit.json ou na pasta customizada definida por bancoz.path(). 
await bancoz.limite('usuarios.json', 100, 500);
await bancoz.limite('usuarios.json', null); // Remove limites
PT criarID(chars?, length?) EN createID(chars?, length?)
Gera ID único. chars="auto" usa alfanumérico, length="auto" gera 12-32 chars. 
const id = bancoz.criarID();           // timestamp-random
const custom = bancoz.createID('ABC', 4); // timestamp-ABCA
PT getLimite(arquivo) EN getLimit(file)
Retorna limites, uso atual e restante para arquivo. 
const status = await bancoz.getLimite('usuarios.json');
console.log(status.restante.nodes); // 45 disponíveis

📏 Limites Avançados v2.0.0

✅ Novo na v2.0.0: Limites por nível de profundidade (depth). Controle granular de estrutura JSON.

🔢 Contagem Estrutural por Profundidade

Sistema de contagem preciso:
Termo Definição Exemplo JSON
keys Quantidade de propriedades/chaves no nível { "a":1, "b":2 } → 2 keys
nodes Itens raiz do nível (objetos/arrays contam como 1 cada) { "user": {...} } → 1 node
subnodes Elementos filhos recursivos do nível { "user": { "info": {} } } → 1 subnode (depth 1)

Exemplo de Depth:

{
  "users": {           // ← Depth 0: 1 key/node
    "user1": {         // ← Depth 1: 1 key
      "nome": "João",  // ← Depth 2: 2 keys (nome,idade)
      "idade": 30
    }
  }
}

Contagem: depth 0: keys=1 | 1: keys=1 | 2: keys=2

PT limiteAvancado(arquivo, limitesPorNivel) EN advancedLimit(file, limitsByDepth)
Define limites granulares por nível de profundidade no arquivo BANCO Z/configs/bancoz/advanced-limits.json.
Validação automática em criar() e atualizar()
Parâmetros:
  • arquivo (string): Nome do arquivo
  • limitesPorNivel (object): {"0": {maxKeys:10, maxNodes:50}, "1": {maxSubnodes:20}}
Exemplo: 
await bancoz.limiteAvancado('demo.json', {
    "0": { maxKeys: 3, maxNodes: 5, maxSubnodes: 2 },
    "1": { maxKeys: 2, maxSubnodes: 3 }
});
PT getLimiteAvancado(arquivo) EN getAdvancedLimit(file)
Retorna status completo com limites, uso atual por profundidade e slots restantes.
Exemplo: 
const status = await bancoz.getLimiteAvancado('demo.json');
console.log(status);
console.log(`Restante depth 0: ${status.restante['0'].keys} chaves`);
🔧 Integração Automática: Verificado automaticamente em criar() e atualizar(). Lança erro se excedido.

⚠️ Importante:
  • Nomes de arquivo não podem conter barras (/) ou barras invertidas (\)
  • Arquivos são sempre salvos na pasta "BANCO Z"
  • A extensão .json é adicionada automaticamente
  • Em caso de erro com backup ativo, o arquivo original é restaurado
✅ Boas Práticas:

  • Mantenha o backup ativo em produção
  • Use logs para debugging
  • Faça validações antes de salvar dados sensíveis
